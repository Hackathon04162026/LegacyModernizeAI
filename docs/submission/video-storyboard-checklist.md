# LegacyModernizeAI Video Storyboard Checklist

Use this alongside `video-script-final.md`. It is a simple production checklist for a short demo video that feels polished, clear, and enterprise-friendly.

## Video Goal

Show how LegacyModernizeAI helps teams understand legacy applications, reduce onboarding friction, find modernization risks, generate documentation, and build confidence in the migration path.

## Visual Style

- Clean screen captures
- Simple cursor movement
- No jargon-heavy overlays
- Keep text large enough for a conference room or judge screen
- Use only the most important UI areas

## Storyboard Checklist

### Scene 1: Opening
- Show the title screen
- Show the Home page landing area
- Start with a calm, confident introduction

Checklist:
- [ ] Title visible
- [ ] Brand name visible
- [ ] Short enterprise value statement visible

### Scene 2: Home
- Show repository input or sample folder selection
- Point out the quick analysis button
- Show that the workspace is easy to start

Checklist:
- [ ] Home section visible
- [ ] Input field visible
- [ ] Quick analysis button visible
- [ ] Browse sample folders visible

### Scene 3: Quick Analysis
- Click quick analysis
- Show progress loading clearly
- Wait for completion before moving on

Checklist:
- [ ] Loading state visible
- [ ] Progress bar visible
- [ ] Button disabled during analysis
- [ ] Results appear only after loading finishes

### Scene 4: Overview
- Show the overview summary cards or metrics
- Focus on readiness and current-state understanding
- Keep this framed as business value, not technical detail

Checklist:
- [ ] Overview page visible
- [ ] Metrics visible
- [ ] Summary understandable without explanation

### Scene 5: Analysis
- Show findings and risk areas
- Highlight security, complexity, and PII concerns
- Emphasize risk reduction and early visibility

Checklist:
- [ ] Analysis page visible
- [ ] Security findings visible
- [ ] Complexity hotspots visible
- [ ] PII or sensitive data callouts visible

### Scene 6: Documentation and Confluence
- Show the documentation page
- Show the Confluence-ready output
- Explain onboarding and handoff value

Checklist:
- [ ] Documentation page visible
- [ ] Confluence references visible
- [ ] One or more rows readable

### Scene 7: Roadmap
- Show the migration roadmap
- Explain phased execution and effort planning
- Call out manual versus AI-assisted value

Checklist:
- [ ] Roadmap page visible
- [ ] Phases visible
- [ ] Effort comparison visible

### Scene 8: Sample Generation
- Show the target selection area
- Show the sample generation step
- Explain how this helps stakeholders picture the end state

Checklist:
- [ ] Sample generation section visible
- [ ] Target selection visible
- [ ] Generated output visible

### Scene 9: CI/CD Value
- Show the delivery flow or CI/CD reference
- Keep the message focused on repeatability and enterprise fit

Checklist:
- [ ] CI/CD section visible
- [ ] Delivery value easy to understand

### Scene 10: Closing
- Return to the core value message
- End with confidence and a clear enterprise outcome

Checklist:
- [ ] Closing statement visible
- [ ] Value proposition easy to repeat verbally

## Recommended Capture Order

1. Home
2. Quick Analysis
3. Overview
4. Analysis
5. Documentation and Confluence
6. Roadmap
7. Sample Generation
8. CI/CD Value
9. Closing

## Final Review Before Export

- [ ] All screenshots are readable
- [ ] Script matches the on-screen order
- [ ] No deep technical jargon is required to understand the story
- [ ] Enterprise value is clear in every scene
- [ ] The final video stays within 3 to 5 minutes
